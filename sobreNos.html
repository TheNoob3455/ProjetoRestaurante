Um pouco sobre nós

Nós, alunos do SENAI, estamos desenvolvendo este projeto como parte do nosso aprendizado em desenvolvimento web. O Chapa Quente é uma hamburgueria fictícia criada para demonstrar nossas habilidades em HTML, CSS, JavaScript, Java, Spring Boot, MySQL, JPA, Lombok, entre outras tecnologias. Buscamos proporcionar uma experiência interativa e agradável para os usuários.

Durante o desenvolvimento do projeto, tivemos a oportunidade de aprender coisas novas e melhorar conhecimentos que já tínhamos. Algumas tecnologias já eram conhecidas por nós, enquanto outras fomos aprendendo conforme surgiam novas necessidades. Acreditamos que a prática é uma das melhores formas de aprender, e esse projeto tem nos ajudado bastante nesse processo.

Sobre o projeto

A ideia do Chapa Quente surgiu com o objetivo de simular o funcionamento de uma hamburgueria por meio de um sistema web. Pensamos em criar um site onde os clientes pudessem visualizar o cardápio, personalizar seus pedidos e reservar mesas.

Além disso, desenvolvemos uma área administrativa para facilitar o controle dos pedidos, das mesas disponíveis e do estoque de ingredientes.

Nosso Desenvolvimento

Para organizar melhor o desenvolvimento, dividimos as tarefas entre os integrantes da equipe. Enquanto uma parte ficou responsável pela estrutura e aparência das páginas, utilizando HTML e CSS, a outra trabalhou nas funcionalidades e na integração do sistema com o banco de dados.

Durante esse processo, enfrentamos algumas dificuldades, principalmente na hora de fazer as diferentes partes do site funcionarem juntas. Porém, esses desafios também nos ajudaram a entender melhor as tecnologias utilizadas e a encontrar soluções para os problemas.
